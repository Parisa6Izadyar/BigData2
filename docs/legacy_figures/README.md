# Historical figures

These images were supplied with the original project. They are retained for reference and use a different or undocumented evaluation setup.

The original repository notebook contains SARIMAX code. A later supplied notebook also contains XGBoost training, with test-label early stopping and observed held-out target lags. Those results use a different evaluation setup from a fixed-origin forecast. LSTM imports are present, but no training or evaluation was supplied. The old full-series figure also combines in-sample fitted values and a held-out forecast; those portions should not be interpreted as one independent test.

Use plots and metrics generated together by the current workflow for new comparisons. The recorded statistical-model benchmark is documented in the main README. The workbook's upstream preparation remains unspecified.
